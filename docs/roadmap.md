# Roadmap

This roadmap is intentionally practical. Virtuoso should stay lightweight, understandable, and useful on ordinary laptops.

## Near Term

- [ ] Add `--doctor --json` for automated diagnostics.
- [ ] Add Ollama and LM Studio provider presets.
- [ ] Add dashboard streaming over Server-Sent Events or WebSockets.
- [ ] Add screenshot tests for the browser dashboard.
- [ ] Add a real demo GIF/video to the README.
- [ ] Add a config validation command for CI and support requests.

## Contributor-Friendly

- [ ] Add more `good first issue` tasks after launch.
- [ ] Split provider setup docs into short provider-specific pages.
- [ ] Add a small plugin/provider interface.
- [ ] Add examples for common bugfix/refactor/test workflows.

## Larger Ideas

- [ ] Project indexing with a small local cache.
- [ ] Safer command execution modes.
- [ ] One-click Windows installer.
- [ ] Better local-model setup wizard.
- [ ] Optional telemetry-free usage metrics stored locally.

## Non-Goals

- Requiring a high-end GPU.
- Becoming a large IDE replacement.
- Running untrusted code in a security-critical sandbox.
