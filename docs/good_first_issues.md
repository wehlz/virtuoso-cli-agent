# Good First Issues

Use these as starter issues after the repository is public.

## Documentation

- Add a real dashboard demo GIF to `docs/assets/`.
- Add provider-specific setup pages for OpenRouter, Groq, Together, and OpenAI.
- Add a troubleshooting page for common API key and model errors.

## Dashboard

- Add keyboard shortcuts for Run, Cancel, and mode switching.
- Add a small output copy button.
- Improve mobile layout for narrow screens.

## CLI

- Add `--doctor --json` output.
- Add `virtuoso config path` and `virtuoso config open` helpers.
- Add a compact `--no-browser` dashboard flag.

## Backends

- Add Ollama provider preset.
- Add LM Studio provider preset.
- Add tests for OpenAI-compatible provider selection.

## Testing

- Add dashboard screenshot smoke tests.
- Add package-install smoke tests to CI.
- Add standalone build smoke tests on release tags.
